# 🧊 3D Cube Animation

A simple and elegant **3D rotating cube** built using **HTML and CSS**, showcasing modern CSS techniques like transforms, perspective, and animations.

---

## 🚀 Live Demo

🔗 https://sunilgowda2003.github.io/3D-Cube/

---

## ✨ Features

* Pure HTML & CSS (no JavaScript)
* 3D transform effects
* Smooth infinite rotation
* Clean and minimal UI
* Centered layout using Flexbox

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Transforms, Animations, Perspective)

---

## 📁 Project Structure

```
3D-Cube/
│── index.html
│── box.css
```

## ⚙️ How to Run

1. Clone the repository
   git clone https://github.com/Sunilgowda2003/3D-Cube.git

2. Open the folder
   cd 3D-Cube

3. Open `index.html` in your browser
